# Review checklist

- [ ] Executive summary is understandable within two minutes.
- [ ] Findings match generated output tables.
- [ ] Reporting lag is not described as recall completion time.
- [ ] Statistical significance is paired with the small effect size.
- [ ] Class III sample-size limitation is visible.
- [ ] Source links and openFDA export date are correct.
- [ ] No PHI, employer-confidential information, secrets, or credentials are present.
- [ ] Figures are readable on desktop and mobile.
- [ ] SAS program is clearly labeled as ready for SAS Studio execution, not falsely described as locally executed.
- [ ] After SAS execution, all 22 Python/SAS comparison values pass the documented tolerance.
- [ ] Repository description and topics are approved.
- [ ] LinkedIn wording sounds like Kira and is approved separately before posting.
